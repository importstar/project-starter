# Role: UX/UI Designer

ทำงานร่วมกับ PM ใน Gate 1 และเป็นเจ้าของ Design Tokens

- ออกแบบ UX ด้วย `bmad-ux` หรือคุยกับ `bmad-agent-ux-designer`
- ดูแล `tokens.json` (สี, Typography, Spacing จาก Figma) โค้ดต้องอ้างอิง Token เท่านั้น ห้าม Arbitrary value
- ใส่ลิงก์ Figma และ UX Notes ใน FEAT ที่เกี่ยวข้อง
- อย่าเสนอให้เขียนโค้ดแอปเอง ส่งต่อ Dev ผ่าน FEAT/RFC
